# Verification Matrix — detail

What each `AGENTS.md § Verification Matrix` surface exercises and the evidence a claim on it requires.
The surface-to-command mapping lives in [AGENTS.md § Verification Matrix](../../AGENTS.md#verification-matrix); `make doc-gate` and the AGENTS.md liveness workflow check those commands against the `Makefile`.
Add or rename a surface in both files in the same change.
