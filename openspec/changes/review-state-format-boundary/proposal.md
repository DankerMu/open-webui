# Exclude generated review state from formatting

## Why

Issue #221 identifies a formatter boundary error: machine-local review state is selected by the repository-wide JSON glob. Reformatting that state does not fix the boundary.

## Risk triage

Issue type: bugfix
Fixture level: expanded
Upstream suggested level: absent; shared formatting gate configuration triggers expanded.
Blast radius: source formatting enforcement.
Selected risk packs: script entry; config; file ownership; compatibility; documentation.
Evidence floor: actual Prettier selection RED/GREEN, full `make fmt-check` positive/negative/restoration in an owned source copy, unchanged generated bytes and tracked-file enforcement.

## What Changes

- Add an exact generated-state exclusion to `.prettierignore`.
- Preserve the Makefile glob, every existing ignore rule, formatter options/version and gate state format.

## Capabilities

### New Capabilities

- `source-format-boundary`: generated review state does not affect tracked-source formatting enforcement.

### Modified Capabilities

None.

## Impact

One formatter ignore policy; no application or local gate-script changes.
