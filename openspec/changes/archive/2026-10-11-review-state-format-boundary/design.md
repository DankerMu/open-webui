# Generated-state formatter boundary

## Context

The reported formatter failure is ground truth. `.review-gate.json` is absent after gate closure in the current checkout.
The Makefile runs Ruff first and then a repository-wide Prettier glob.

## Decisions

Change surface: `.prettierignore` only; add the exact review-gate filename, not a JSON wildcard or directory-wide exclusion.
Governing invariant: generated review state cannot fail formatting, but malformed formatting in tracked source still does.
Must preserve: Makefile checks/glob, existing ignore rules, formatter options/version, gate script and generated bytes.
Sibling surfaces: `make fmt-check`, `make fmt`, and direct Prettier selection using the shared ignore policy.
Seams under test: actual Prettier file selection and actual Make target, not source-text assertions.
Use a complete disposable copy of the frozen tracked tree, installed dependencies linked read-only by convention, and an independent temporary Git index for tracked JSON witnesses.
Only that owned copy receives deliberately nonformatted gate JSON or a nonformatted copy of tracked `knip.json`; the working checkout's source and real gate remain untouched.
Capture baseline policy selecting the generated witness as semantic RED; do not rerun the historical error merely to confirm it.
After the fix, full `make fmt-check` must succeed with the nonformatted state unchanged.
Then compact the tracked JSON without changing parsed content: full `make fmt-check` must fail and identify that file.
Restore the tracked file exactly: the same Make target must return to GREEN with the generated state still unchanged.
Record paths, content hashes, command output/exits and cleanup.

## Risks / Trade-offs

An overbroad ignore can mask source drift; the tracked JSON negative control prevents that.
Unrelated baseline formatting failures are not silently ignored or rewritten; retain and diagnose them if encountered.
Changing the generator to emit formatter-specific bytes couples local tooling to repository style and does not define ownership.
No permanent tests that merely assert ignore-file text; retain actual tool evidence instead.
No application/UI/dependency change; rollback is reverting the ignore rule.
Review focus: exact exclusion scope, both Make commands consuming it, negative control sensitivity, source/state preservation.
